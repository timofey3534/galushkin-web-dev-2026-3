# Лабораторная 3 — теория для защиты

Форма заказа: `form`, `label`, `input`, `select`, `textarea`,
`fieldset`, валидация браузером, отправка POST на httpbin.

## Форма

- `<form action="https://httpbin.org/post" method="post">` —
  `action` задаёт адрес отправки, `method="post"` — метод HTTP.
  POST прячет данные в тело запроса (в отличие от GET, где всё
  видно в URL). httpbin.org/post показывает принятые данные —
  так проверяем отправку.
- Данные уходят парами `name=value`, где `name` — атрибут `name`
  поля. Без `name` поле не отправляется.

## Связка label — поле

- `<label for="soup">` + `<select id="soup">` — `for` равен `id`.
  Клик по label ставит фокус в поле (важно для доступности
  и мобильных). Для чекбоксов/радио label оборачивает input —
  тоже валидная неявная связка.

## Типы input

- `text` — имя, адрес. `email` — браузер сам проверяет наличие `@`.
- `tel` — телефон (на мобильных открывает цифровую клавиатуру).
- `checkbox` — `checked` = галочка по умолчанию, `value="yes"` —
  что уйдёт на сервер, если отмечен.
- `radio` с одинаковым `name="delivery_time"` — группа: выбрать
  можно только один. `required` у группы требует выбора.
- `time` — `min="07:00" max="23:00"` ограничивают диапазон,
  `step="300"` — шаг 300 секунд = 5 минут.

## Select

- Первый `<option value="">` с пустым value — плейсхолдер
  («-- Выберите суп --»). Вместе с `required` на select форма
  не отправится, пока не выбрана опция с непустым value.
- `value` на английском (`gaspacho`, `lasagna`) — чтобы сервер
  получал понятные ключи, а не русский текст.

## Textarea и fieldset

- `<textarea rows="6">` — многострочный комментарий.
- `<fieldset>` + `<legend>` — группировка радио-кнопок
  с общей подписью «Время доставки:».

## Кнопки

- `type="submit"` — отправляет форму (сначала браузер проверяет
  все `required` и типы). `type="reset"` — очищает все поля.
- Кнопка без `type` внутри формы по умолчанию submit — поэтому
  «Добавить» в карточках лабы 2 имеет `type="button"`.

## Браузерная валидация

- `required` — поле обязательно. Пустой required select/input
  блокирует отправку и показывает подсказку сам браузер,
  JavaScript не нужен.

2. Как label связывается с полем? — `for` = `id`, либо обёртка.
3. Зачем value на английском? — понятные ключи для сервера.
4. Как работает required на select? — пустой value не проходит.
5. Чем radio отличается от checkbox? — один выбор против многих.
6. Что делает step у time? — шаг изменения в секундах.
7. Зачем fieldset/legend? — смысловая группировка + подпись.
8. Куда и что отправляется? — пары name=value POST на httpbin.
